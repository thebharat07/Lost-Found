# Lost and Found Project

Welcome to the **Lost and Found** project! This application allows users to post items they find, search for lost items, and track their status. The goal is to provide an easy way for people to connect and reclaim lost belongings.


## Tech Stack

- **Frontend**: React.js, Vite  
- **Backend**: Node.js, Express  
- **Database**: File System
- **Authentication**: JWT (JSON Web Tokens)  
- **Styling**: Tailwind CSS (Responsive Design)  

## Features

✅ **User Authentication**  
- Register, login, and logout with JWT-based security.  

✅ **Item Management**  
- Post lost/found items with details (name, category, description, location, time).  
- Edit or delete your posted items.  

✅ **Search & Filter**  
- Search items by category, location, or date.  

✅ **Dashboard**  
- View and manage your posted items in one place.  


## Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/thebharat07/lost-and-found.git
cd lost-and-found
```

---

### 2. Install Dependencies
```bash
npm install  # Install frontend and backend dependencies
```

---

### 3. Run the Application
```bash
# Start the backend server
npm run server

# In a new terminal, start the frontend
npm run dev
```
Frontend: http://localhost:5173  
Backend: http://localhost:5000
